# 확정사항 및 미정 사항

## 확정 (2026-10-24)
- 기준: 최종 회의 문서의 3. 결정사항 + 이후 대화의 사용자 수정.
- 사용자: 효성티앤씨 해외영업·마케팅 담당자. 대상 시장 브라질, 제품 리젠 T2T.
- 서비스(대시보드)명: fionex (2026-10-24 확정).
- 홈(정은진), 시장 분석(한윤수), 제품소개서(유정현), 그린 클레임(김민정), 홍보 스튜디오(한윤수/정은진).
- 홍은주의 기능 담당은 미정. 개인 기록 폴더는 제공.
- 인증 갭 분석 및 문구 검수는 포함. 고객 일정·결제 관리는 확장 영역.
- 개발 도구 Claude Code, 서비스 AI 서버 OpenAI API. Gemini 적용 금지.
- 로그인 없음, 탭 간 자동 연동 없음.
- 사용자 파일/결과 장기 저장·이력·재접속 복원 없음. 결과는 PDF 다운로드.
- 같은 페이지에서 탭 이동 시 입력·파일·결과 유지. 전체 새로고침/종료에는 경고, 복원 없음.
- 공통 디자인은 팀 선정 후 적용. 구조/규칙 → 디자인 → 공통 동작 → 개별 기능 순서.

## 공통 OpenAI 연결 (2026-10-25, 담당 유정현)
- 공통 OpenAI 연결은 유정현 담당(팀 확인, 중복 작업자 없음).
- 기존 텍스트 전용 계획에 사용자 지시로 **공통 이미지 생성 연결**이 추가 요청됨. 어느 탭에서 어떤 이미지를 만드는지는 미정.
- 첫 구현 범위: 텍스트 → 구조화 결과(Responses API), 텍스트 프롬프트 → PNG 1장(Images API). 공용 HTTP 엔드포인트 없음.
- 환경변수: `OPENAI_API_KEY`(공통), `OPENAI_MODEL`(텍스트), `OPENAI_IMAGE_MODEL`(이미지). 모델은 코드에 고정하지 않음.
- 모델 초기 후보: `gpt-5.4-mini`(텍스트), `gpt-image-2.5-sunburst`(이미지). 최종 선정 전.
- SDK: openai 3.37.0(jasonenv 설치, 모의 테스트 통과). 사용법은 docs/data_contracts.md.
- 검증 상태: 2026-10-25 사용자 직접 실행 결과를 전달받아 텍스트·이미지 공통 함수의 실제 호출과 반환 형식을 확인. 업무 결과 품질·비용·소요 시간·응답 모델명·사용량은 미검증.
- PDF 입력(2026-10-25 추가, 담당 유정현): `generate_structured_from_pdf`(OPENAI_MODEL, input_file base64 직접 포함, 고정 파일명 document.pdf, detail high,
  timeout 120초, 재시도 0, store=False)와 `inspect_pdf`(파일 1개·10 MiB·20쪽, 서명·구조·암호화·페이지 검사). PDF 검사는 pypdf 6.21.2.
  모의 테스트 통과. 2026-10-25 사용자 직접 실행 결과를 전달받아 gpt-5.4-mini-2026-03-17에서 텍스트 PDF(3쪽) 1회 실제 호출·구조화 응답 반환을 확인(연결 확인용 최소 추출).
  스캔 PDF 판독·전체 추출 정확성·비용 금액·소요 시간은 미검증. 제품소개서 업로드 라우트·화면 연결은 미구현.
- 제외: 이미지 분석 입력, Files API, 이미지 편집·참조 이미지, 영상, 스트리밍, 캐시·DB.
- 2026-10-25 정은진: 홍보 스튜디오 장면 이미지(첨부 제품 사진 참고) 요구로 `generate_image_from_references`(참조 이미지) 함수를 공통에 추가.
  기존 함수 미수정, 모의 테스트만 통과. **공통 담당(유정현) 검토·합의 전**이며 위 '제외' 항목의 변경 여부는 검토 후 확정한다.
  같은 작업에서 requirements.txt에 fpdf2(홍보 스튜디오 PDF)를 추가했다. 팀 공통 PDF 도구 확정은 아니다.

## 설계 기준
- Flask + HTML/CSS/JS 구조, Conda jasonenv/Python 3.11을 기준으로 패키지 준비.
- 서버/API 구현과 배포 플랫폼 선정은 후속 단계. Render나 Vercel 설정을 임의 추가하지 않음.

## 미정: 담당자 확인 후 명세 갱신
- 디자인 값·이미지·폰트 사용권.
- 홈 보고서가 고정 PDF인지 동적 보고서인지.
- 제품소개서 템플릿·지원 형식·이미지 추출/별도 업로드·바이어 입력.
- 인증 요구사항/보유 증빙의 데이터 확보와 검수 기준.
- 콘티 출력 형식·이미지 생성 포함 여부·공동 담당 세부 분담.
- OpenAI 모델 최종 선정(위 후보의 실제 호출 검증 전), 비용 한도·호출 제한 운영 기준, 배포 환경.
- (확정 2026-10-25) PDF 출력 도구: ReportLab 5.1.0(BSD), 글꼴 Noto Sans KR(OFL, features/market_analysis/fonts). 공통 담당 합의는 한윤수 확인. 공통 PDF 입력 검사(pypdf)와 별개.
- PDF 입력 detail(high 유지 여부)·크기·페이지 상한의 실제 호출 기반 조정, 업로드 라우트의 요청 전체 크기 제한.
- 이미지 생성을 사용할 탭과 이미지 용도·출력 방식.
- PR 승인/병합 담당.
