# 시장 분석 테스트
실제 ComexStat 요청을 보내지 않는 모의 테스트입니다(프로젝트 루트, Conda jasonenv).
```
python -m unittest discover -s tests/test_market_analysis -v
```
- 입력 검증: 코드 체계·자릿수·점 제거, 기간 역전·120개월 초과·최신 월 초과, 공급국 코드
- 계산: 가중 평균단가, 전년 동기·동월 증감률과 계산 불가 사유, 기록 없는 월, 중량 0·결측, 단가 확인 필요, 순위·비중·한국 별도 표시
- 조회 흐름: 전체 연도 요청 범위, 같은 날 캐시 재사용, 다시 불러오기, 실패 시 이전 자료, 없는 코드와 결과 없음 구분
- ComexStat 호출: 요청 본문, HS 6자리 필터명, 429·5xx 최대 2회 재시도, 400 미재시도, 응답 형식 오류
- 라우트: 입력 오류 400 + fields, 소스 오류 상태 코드, meta 기본값·소스 장애
수치는 산식 확인용 가상 값입니다. 실제 통계 대조는 docs/worklogs/han_yunsu/validation.md에 기록합니다.
