## 웹 게시본과 PDF 대조 (CONAR)
Seção 10과 Anexo "U" 구간을 공백·따옴표·대시를 정규화한 뒤 단어 단위로 비교했다.
- Seção 10: 차이는 목록 기호(a.~h., a.~f.)가 PDF에만 있는 것(웹은 HTML 목록 서식)과 "greenwashing" 뒤 마침표 1개.
- Anexo "U": 차이는 PDF 추출의 하이픈 손실("exigindo-se"→"exigindose"), 각주 번호 띄어쓰기, 각주 위치(PDF는 페이지 중간)뿐. 실질 문구 차이는 발견하지 못함.
- 웹 원문 일부에 역슬래시가 붙은 따옴표(\”livre de\”)가 있음. 원문 게시 형식 그대로이며 의미 차이 없음.
- 같은 코드 안에서 Artigo 36-B의 원칙 목록과 Anexo U II의 원칙 목록은 순서와 일부 문구가 다르다(예: Concretude). 해석은 원문으로 확인 필요.

- 사전 명시 허가 없이 금지: (a) 상업·광고 목적 이용, (b) 체계적 전체 복제·재배포·경제적 이용, (c) AI 시스템·언어모델·알고리즘의 학습·개발·개선·입력(alimentação)을 위한 추출·마이닝·자동 수집 또는 이용.
