자료 선택

소개서에 사용할 한국어 제품 자료 PDF 1개를 선택합니다.

PDF 1개, 최대 10 MiB·20쪽. 스캔 PDF도 분석을 요청할 수 있지만 판독 품질은 아직 확인하지 않았습니다. 화면에서는 확장자·빈 파일·크기만 확인하고, 실제 PDF 형식·손상·암호화·페이지 수는 서버에서 검사합니다. 파일은 영구 저장하지 않습니다.

선택된 파일이 없습니다.

API 없이 확인·수정 화면을 점검하기 위한 고정 예시입니다. 선택한 PDF를 읽거나 업로드하지 않습니다.

분석 결과 확인·수정

항목별 값과 상태·가상·확인 여부를 검토합니다.

아직 분석 결과가 없습니다

PDF를 선택하고 "PDF 분석"을 누르세요. API 없이 화면만 점검하려면 "개발용 예시 불러오기"를 사용하세요.

개발용 예시입니다. 업로드한 PDF의 분석 결과가 아닙니다.

값은 화면 확인용 고정 예시이며 효성티앤씨의 공식 제품 사양·공급 조건이 아닙니다. 근거 위치와 원문 발췌는 없습니다.

PDF 분석(AI 추출) 결과입니다. 사용자 확인 전에는 확정 정보가 아닙니다.

페이지·발췌는 AI가 제시한 근거이며 원문 대조는 하지 않았습니다(원문 대조 미실시). 값과 근거를 원문에서 직접 확인하세요.

검토 방법

  • "사용자 확인"은 검토했다는 표시이며 원문 대조·사실 검증·인증 완료를 뜻하지 않습니다.
  • 값을 수정하면 그 항목의 사용자 확인이 해제됩니다.
  • 자료(예시 또는 AI 추출)에서 가상으로 표시된 값은 "가상 정보" 표시를 해제할 수 없습니다.
  • 상태: "문서에서 추출"은 AI가 근거와 함께 읽은 값, "확인 필요"는 불명확·근거 부족·충돌, "문서에서 찾지 못함"은 AI가 찾지 못한 항목입니다.
  • 값이 없던 항목에 입력한 값은 사용자 추가 정보로 구분되며 문서 근거가 아닙니다.
카탈로그 표시명

위 "제품명" 항목(원본)은 그대로 두고 카탈로그에만 이 표기를 씁니다. 원문에 있는 표기만 쓰고 공식 영문명을 임의로 만들지 마세요.

카탈로그 미리보기

"디자인 시안 보기"는 4페이지 레이아웃을 검토하기 위한 고정 예시입니다(분석 결과·수정값을 쓰지 않고 API를 호출하지 않음). "생성 결과 보기"는 마지막으로 성공한 카탈로그 생성 결과를 같은 디자인으로 보여 줍니다.

아직 생성 결과가 없습니다.
